# Laxify API

Бэкенд приложения Laxify: аккаунты, плейлисты, избранное, история, статистика,
рекомендации и админка. FastAPI + PostgreSQL + Redis, разворачивается через
Docker Compose, HTTPS выдаёт Caddy.

## Что уже умеет

| Раздел | Возможности |
|---|---|
| Авторизация | Вход через Google (проверка подписи ID-токена), JWT + refresh с ротацией, список устройств, выход на одном или всех устройствах |
| Профиль | Имя, юзернейм (с проверкой занятости и подсказками), аватар, дата рождения, приватность профиля и статистики, онбординг |
| Соцфункции | Публичные профили, поиск людей, подписки, счётчики подписчиков |
| Избранное | Синхронизация, массовое добавление, дизлайки (снимают лайк автоматически) |
| Плейлисты | Создание, редактирование, обложка, приватность, перестановка треков, совместное редактирование по приглашению, шаринг по ссылке |
| Активность | История прослушивания пачками, история поиска, отметки загруженных треков |
| Статистика | Часы прослушивания, стрики по дням, топ артистов и треков |
| Рекомендации | Профиль вкусов по прослушиваниям и лайкам с затуханием по времени, исключение дизлайков и недавно слышанного |
| Админка | Сводка, поиск пользователей, бан/разбан, пул ключей доступа, журнал действий |

Полная документация API поднимается сама на `/docs` (в проде отключена).

## Первый запуск

```bash
cd backend
cp .env.example .env
```

В `.env` обязательно заменить:

- `POSTGRES_PASSWORD` — пароль базы (используется и в `DATABASE_URL`)
- `JWT_SECRET` — случайная строка от 32 символов: `openssl rand -hex 32`
- `GOOGLE_CLIENT_IDS` — iOS client ID из Google Cloud Console

В `Caddyfile` заменить домен на свой и направить на сервер A-запись.

Сгенерировать первую миграцию и поднять всё:

```bash
docker compose run --rm api alembic revision --autogenerate -m "init"
docker compose up -d --build
```

Проверить:

```bash
curl https://ваш-домен/health
```

## Как стать администратором

Права выдаются по Google `sub` — он появляется в базе после первого входа:

```bash
docker compose exec db psql -U laxify -d laxify -c "SELECT google_sub, email FROM users;"
```

Найденное значение добавить в `ADMIN_GOOGLE_SUBS` в `.env` и перезапустить
(`docker compose up -d api`), либо выдать права напрямую:

```bash
docker compose exec db psql -U laxify -d laxify -c "UPDATE users SET is_admin = true WHERE email = 'ваша@почта';"
```

## Ключи доступа к музыке

Ключи хранятся в базе, а не в конфиге, чтобы их можно было добавлять и
отключать без передеплоя. Первый можно занести через `YANDEX_TOKENS` в `.env` —
он попадёт в пул при старте. Дальше — через админку (`POST /admin/tokens`).

Сервер сам подбирает наименее нагруженный рабочий ключ, а ключ, который начал
стабильно отдавать ошибки, автоматически выводится из пула, чтобы не долбить
сломанную учётку.

## Проксирование музыки

Сейчас **выключено** (`MUSIC_PROXY_ENABLED=false`) — и это осознанно.

Сервер стоит во Франкфурте, а источник музыки не обслуживает европейские
адреса. Если включить прокси на этом сервере, музыка перестанет грузиться
вообще, а не только под VPN: сейчас запрос уходит с телефона, то есть с
российского адреса, и работает.

Код прокси написан и лежит в `app/services/yandex.py` и `app/api/v1/music.py`.
Когда появится хост с российским IP, достаточно:

1. `MUSIC_PROXY_ENABLED=true`
2. `MUSIC_PROXY_UPSTREAM` — адрес, через который ходить (или пусто, если API
   вызывается напрямую с этого же сервера)

Приложение узнаёт режим через `GET /music/status` и переключается само, без
новой сборки.

## Обслуживание

```bash
docker compose logs -f api          # логи
docker compose exec db pg_dump -U laxify laxify > backup.sql   # бэкап
docker compose up -d --build api    # обновление после git pull
```

Миграции применяются автоматически при старте контейнера `api`.
